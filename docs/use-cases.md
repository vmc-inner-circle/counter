## UC-1 피부과 예약 — Muse · 영어 (기준 흐름)

**사전 조건:** 피부과가 Counter에 영업시간, 시술, 가격, 접근성, 빈 슬롯을 등록해 두었다.

1. 사용자가 Muse에게 영어로 부탁한다: "Find skin care aesthetic in Korea"
2. Muse가 검색과 Google Maps로 가게를 찾고, 연락처에서 **Counter URL을 발견**한다
3. Muse가 Counter에 문의한다. 등록된 정보(접근성 등)는 Counter가 **바로 답한다**
4. Muse가 예약을 요청하면 Counter는 슬롯을 잡아 두고 **원장에게 승인을 묻는다**
5. 원장이 폰에서 **승인**한다
6. Counter가 Muse에게 확정 번호를 주고, **Muse가 사용자에게 예약 완료를 알린다**

**성공 조건:** 사람이 전화를 한 통도 걸지 않고 받지도 않는다. 원장은 탭 한 번만 한다. 사용자가 확정 번호를 받는다.

**현재 구현과 다른 점**
- 완료 알림: 회의에서는 접수할 때 Muse의 이메일을 받아 두고 승인되면 메일로 알리기로 했다. 지금은 Muse가 `GET /tasks/:id?wait=60`으로 기다렸다가 받는다(롱폴링). 영상에서는 차이가 보이지 않는다
- 루트 README의 데모 프롬프트는 일본인 휠체어 사용자(Yuki) 버전이다. UC-1을 영어 사용자로 바꿀지는 **미정**

## UC-2 식당 예약 — Pickle · 중국어

UC-1과 흐름이 같다. 업종은 식당, 에이전트는 Pickle, 사용자 언어는 중국어다.
- 식당 이름, 메뉴, 슬롯, 질문할 내용: **미정**. 식당 seed가 아직 없다
- 영상 문제 제기("바쁜 식당에 AI 전화가 쏟아진다")와 같은 업종이다

## UC-3 숙소 예약 — Dots · 베트남어

UC-1과 흐름이 같다. 업종은 숙소, 사용자 언어는 베트남어다.
- 에이전트: 회의 결정은 **Dots**, `video/demo-clips.md`에는 **Grok**으로 적혀 있다. 다음 싱크에서 하나로 정한다
- 숙소 이름, 객실, 슬롯: **미정**

## UC-4 모르는 질문 → 직원이 한 번 답하고 → Counter가 기억

1. 에이전트가 가게 정보에 없는 것을 묻는다 (예: "일본어 하는 직원 있나요?")
2. Counter가 바로 답을 지어내지 않고 **직원 폰에 질문을 띄운다**
3. 직원이 답하고 **"기억할까요?"를 켠 채로** 보낸다
4. Counter가 그 답을 에이전트에게 전한다
5. **다른 에이전트**가 같은 질문을 하면 직원 없이 바로 답한다

**성공 조건:** 같은 질문으로 직원을 두 번 부르지 않는다.

## UC-5 실측 비교 — 전화 예약 vs Counter

"Counter가 압도적으로 빠르다"를 추정이 아닌 실측 숫자로 영상에 넣는다.

**같게 맞출 조건**
- 과제: 같은 가게, 같은 부탁, 같은 질문 2개(가게 정보에 있는 것 1개, 없는 것 1개), 예약 1건
- 사장님 역할: 양쪽 모두 최수민. 전화는 바로 받는다. 대기나 재통화가 없는, **전화가 가장 잘 풀리는 경우**로 잰다
- 회차: 양쪽 3회씩, 중앙값을 쓴다

**잴 것**

| 지표 | 전화 | Counter |
|---|---|---|
| ① 전체 소요: 에이전트가 과제를 받은 순간 → 사용자에게 확정 보고 | 통화 녹음 + 스톱워치 | 측정 스크립트 타임스탬프 |
| ② 사장님이 붙잡힌 시간 | 통화 시간 전체 | 질문 답변·승인에 쓴 시간 |
| ③ 사장님 개입 횟수 | 받은 전화 수 | 탭 수 |

- ②가 영상의 핵심 숫자다. 문제 제기("AI 전화에 시달리는 사장님")에 바로 답한다
- 에이전트가 다르다는 점은 결과에 적어 둔다: 전화는 Pickle, Counter 쪽은 Claude Code가 에이전트 역할을 한다
- 결과는 `bench/results.jsonl`에 회차마다 한 줄씩 남긴다. 전화 회차는 손으로 적는다

**미정**
- 업종: 식당(UC-2) 추천. 문제 제기와 원래 실측 안(Pickle이 식당 주인에게 전화)에 맞는다. 피부과(UC-1)로 하면 바로 잴 수 있다
- Pickle이 실제 번호로 전화를 걸 수 있는지: **미검증**. 안 되면 대체 수단을 싱크에서 정한다
- 기존 참고치: UC-1+UC-4를 Claude Code로 돌렸을 때 전체 26초(2026-11-09, 직원이 단계마다 약 5초 만에 반응). 위 조건으로 다시 잰 값이 아니다
