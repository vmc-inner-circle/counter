11:30 싱크. 레포·제품 현황 공유 → 각자 영상 시안 리뷰 → 영상 메시지(무엇을 넣고 뺄지) 정리.

## 결정

- **영상 비율 9:16** — 제품 영상은 대부분 9:16으로 만든다
- **메인 플롯은 자동화(에이전트 요청을 Counter가 대신 받아 처리), 글로벌(다국어)은 바로 이어지는 부가가치**로 소개한다 — 자동화가 핵심이고 글로벌은 보강
- **속도(전화보다 빠르다)는 외부 소개 영상에서 뺀다** — 이미 주제가 하나(사장님 안 괴롭힘) + 확장(글로벌)이라 "빠르기까지 하다"를 넣으면 구성이 부자연스럽다. 더 매력적으로 소개할 게 많다
- **기존 예약 플랫폼·에이전트가 이미 하는 일(예약 확정 등)을 효용으로 내세우지 않는다** — "네이버 예약 쓰면 되지 않냐"는 반론이 나오고 효용이 줄어 보인다. 중심은 "전화·인스타·네이버로 흩어져 들어오는 에이전트 요청을 한 곳에서 정리·처리해 사장님이 폰 슬롭에서 벗어난다"
- **요청 흐름이 보여야 한다: 사용자 → 개인 에이전트(Pickle 등) → Counter → 사장님.** 대부분 Counter에서 끝나고 일부만 사장님에게 간다. 여러 에이전트가 한 가게로 몰리는 장면(줌아웃 등)이 있으면 좋다
- **한 컷에 시선은 한 곳** — 한 컷이 2~3초라 읽을 거리가 여러 곳이면 안 된다. 문구도 두 호흡으로 나눠 띄운다
- **영상 스타일은 새로 창작하지 않고 레퍼런스 영상을 찾아 클론한다** — 그냥 만들라고 하면 슬롭이 나온다. 현재 미감은 조순형 안(Notion 레퍼런스)이 가장 좋다는 평이었고, 확정은 다음 싱크
- **다음 싱크 13:15** (12:12 기준 마감까지 2시간 47분)

## 시안 피드백

- **좋았던 점**: 깔끔한 스타일, 인트로가 재미있다
- **Counter가 채팅 UI로 오인된다** — 사용 흐름 화면이 Counter UI처럼 보이는데 Counter는 채팅 인터페이스가 아니다
- 사용자는 "식당 찾아줘"라고만 하고 에이전트가 알아서 탐색·문의를 뿌리는 맥락이 드러나면 좋다
- 승인 버튼이 대화 화면에 나와 "우리가 승인하는" 것처럼 헷갈린다
- Counter 덕분에 에이전트 입장에서도 이득: 무시당하지 않고(수락률 100%) 응답이 빠르다
- "링크" 같은 기술 구현 방식은 거의 안 보여도 된다. Counter 로고만 쓰고, 뒤에 UI 카드가 아니라 **사람(사장님)이 있고 Counter가 앞에서 막아 준다**는 느낌으로
- 일반적인 제품 데모 영상의 편집 스타일을 레퍼런스로 먹이면 좋겠다
- 최종 영상에는 나레이션이 있으면 좋겠다는 의견

## 데모 구성 논의

- 실제 사용자처럼 "근처 식당 찾아줘"로는 Pickle이 임시 호스팅 주소를 못 찾는다 → 프롬프트에 주소를 명시해야 하는데 불편해 보일 수 있다
- 그래서 "이 식당 예약해 줘", "이 식당 ○○ 알려 줘" 같은 **특정 가게 요청 2개 정도**를 보여주자는 제안. 마무리 멘트는 "전화 없이 끝났습니다"(사장님 입장 강조)
- 사장님 화면: 에이전트끼리 처리된 건이 실시간으로 쭉 올라가다가 승인이 필요한 건 하나만 뜨고, 그것만 누르는 장면
- 사장님 화면만으로는 어떻게 만들어진 건지 안 와닿으니, 사용자가 Pickle로 요청하고 쌓이는 쪽도 함께 보여야 한다. 실제 서비스 화면은 사장님 쪽만 데모로 넣고 나머지는 영상(연출)으로 만들자는 의견
- 제품 현황(최수민): 브라우저로 가게 주소에 들어오면 웹 페이지, 에이전트면 마크다운. 일반 채팅 웹 에이전트는 GET만 돼서 문의는 되지만 예약은 안 되고, 예약은 MCP 연동이 필요하다. 사장님 앱은 Today·승인할 것·답변할 것·히스토리, 채널톡을 참고해 바꾸는 중
- 사장님 예약 방식: 문의 응대는 무료, 예약까지 원하면 유료로 예약 시스템 연동. 예약 수락 자동 여부는 권한 레벨로 조정

## 메시지·슬로건 후보

- 문제: 에이전트가 소상공인에게 시도 때도 없이 연락하는데 사람이 다 대응 못 하고, 대응해도 AI라서 끊어 예약률이 떨어진다
- 코어: 에이전트를 컨슈머로 대우하는 프로덕트·인프라가 없다 → Counter는 에이전트 네이티브
- 후보 문구: "더 이상 AI를 사람이 응대하지 말아요. AI는 AI가 응대해야 된다" · "AI 컨슈머를 위한 카운터파트를 만듭니다" · (조순형 시안 문구) "휴대전화는 사람들에게, 카운터는 직원들에게"(전사 그대로 — '에이전트들에게'의 오인식일 수 있음)
- 클로징에 포부: "테크 기업들이 에이전트 확산에 힘쓸 때 우리는 그들을 위한 채널을 판다"
- 시스템은 간략히, 이 문제를 해결하는 제품이라는 것만
