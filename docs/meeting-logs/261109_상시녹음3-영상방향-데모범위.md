## 결정

- **영상은 16:9 가로(YouTube용)로 만든다** — "발표 영상은 16:9가 맞지 않을까" → 전원 동의. 11:30 싱크의 9:16을 뒤집는다 → [`video/README.md`](../../video/README.md) §영상 메시지·연출 원칙 반영
- **심사위원이 직접 접속해 보는 QR·링크는 엔딩에 넣지 않는다** — 심사위원이 자기 에이전트로 한두 건 넣어 봐야 "폭탄처럼 몰리는 요청을 Counter가 쳐내는" 정체성이 안 보이고, 예약만 잘 되면 "AI 네이티브 캐치테이블이구나"로 오해할 수 있다. 개념만 던지고 상상하게 하는 쪽이 낫다 (Counter는 'AI 네이티브 채널톡'에 가깝다)
- **개발은 GitHub 기준 엔드투엔드 동작 + 디자인 손보기까지만** — 시스템의 핵심만 제대로 보여주면 되고 더 붙이지 않는다. 남는 시간은 영상 투입
- **진행: 두 시안을 같이 검토해 한 포맷을 고르고, 그 포맷에서 더하고 빼며 다듬는다. 14:00쯤 마무리 각을 잡고 프로덕션** (13:00 기준 약 2시간 남음)
- **디자인: 프라이머리 컬러를 바꾸고 로고를 급히 만든다** — 모션 그래픽에도 로고가 필요하다
- **영상 결과물(mp4)도 전부 GitHub에 올린다** — 회의에서 반응이 좋았던 안을 서로 참고하기 좋다. 이미 [`video/README.md`](../../video/README.md) §올리는 법에 있음

## 시안 피드백 (황준식·조순형 안)

- 848건 중 사람이 유의미하게 응대한 건 약 100건(실제 미국 사례 숫자) — 더 잘 드러나야 한다. "Everyone loses"가 **왜 졌는지**를 각자 한 줄로: 가게는 귀찮아 죽겠고, 에이전트는 아무도 전화를 안 받아 주고, 사람은 왜 못 찾는지 모른다
- 비포→애프터에서 "졌다 → 이겼다"를 강조하는 건 좋다. 왜 졌고 왜 이겼는지 각각 한 줄
- 솔루션 장면에 사장님만 있어 어색하다 — Counter가 에이전트와 사장님 **사이**에 등장해야 하고, 에이전트도 여러 종류로
- 에이전트들끼리 Counter에서 알아서 처리하는 영역이 보이면 좋다 ("사람은 사람 일, 에이전트는 에이전트끼리")
- "Needs you"(필요할 때만 사람에게 개입 요청)는 좋다
- "Answers once"만 보이면 Counter가 응답을 안 하는 것처럼 보인다 → **에이전트 응답 완료가 쫙쫙 올라가는 화면**이 있어야 한다. 지금 제품엔 그 화면이 없다. UI에서 초록색으로 '자동응답 완료' 강조
- 사람이 에이전트에게 지시하는 장면에서 "이 사람이 에이전트 뒤에 있다"를 화살표로 이어 보여주기
- 화면이 꽉 찬 뒤 줌아웃하며 Counter로 화살표가 꽂히는 연출 — 'front door' 메시지가 그래픽에 표현이 안 되어 있다
- "people"보다 "customer"가 낫다
- "Tech spreads agents"의 주어(테크 기업)가 와닿을지 — OpenAI·Meta·xAI·Anthropic처럼 이름이나 아이콘이 바뀌며 주어가 바뀌는 안
- 슬로건 "테크 기업들이 에이전트를 퍼뜨릴 때 우리는 그들의 카운터를 만든다"는 좋다
- "모든 에이전트, 모든 언어"는 와닿지 않는다
- 뒤쪽 텍스트 구간은 정보가 적다. 사장님 입장이 잘 안 와닿는다(개인 폰으로 오는 건가 오해 가능)
