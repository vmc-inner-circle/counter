# 261109 해커톤 후속 미팅 — 데모 시나리오·영상 흐름 회의 (10:35~10:56경)

R&R·스펙 회의(`261109_현장-RnR-스펙회의.md`) 직후 이어진 회의. 전사 원문: `261109_후속-데모시나리오-영상흐름회의_transcript.md` (클로바노트 화자 번호만 있음 — 아래 발언자는 맥락으로 추정. 레포·시스템 데모를 맡겠다고 한 "발화자 2"를 최수민으로 봄)

## 결정

- **공통 작업 기반 = Counter GitHub repo.** 팀원을 모두 초대하고, 회의록도 마크다운으로 여기에 올린다 (최수민). repo 링크는 디스코드에 새로 판 채널에 공유함 — 채널 이름은 전사상 "ICUIC"로 들려 미검증
- **데모 시나리오를 먼저 고정한다** (최수민). 영상 만들 때도, 제품 경험 설계에도 유리. 최수민은 **시스템 입장의 데모(요청이 어떻게 오고 응답을 어떻게 주는가)**를 만들고, 그 사례를 영상에서 어떻게 소개할지는 영상팀 몫
- **시나리오 3개, 국적·에이전트를 바꿔 보여 준다** — "우리 거 하나면 전 세계 모든 AI 에이전트·모든 국적을 커버"
  | 업종 | 개인 에이전트 | 언어 |
  |---|---|---|
  | 피부과 예약 | Muse | 영어 |
  | 식당 예약 | Pickle | 중국어 |
  | 숙소 예약 | Grok (전사상 불명확) | 베트남어 |
  - 엔딩: 예약 완료 알림 네 개가 탁탁 뜨고 사용자들이 웃으며 보는 컷. 레퍼런스: 여러 언어 에이전트가 한 번에 일을 끝내는 영상
- **최수민은 이 시나리오의 성능 측정(소요 시간 등)이 가능하도록 만든다**
- **영상 흐름(초안)**: 인트로 ~10초(시대 배경) → **문제 제기(problem statement)** → 솔루션 = 시스템 데모(~30초) → 클로징
  - 문제를 먼저 보여 줘야 "얘네가 이걸 풀려고 만들었구나"가 이해된다는 의견 채택. 문제 예: 바쁜 식당에 AI 전화가 너무 많이 와서 사장님이 짜증 남(AI slop)
  - 데모는 영상 큰 줄기 안의 한 부분일 뿐 — 데모가 주제가 되면 흐려진다
  - 이렇게 하면 40초 정도로 짧을 수 있음 → 늘린다면 뒤에 BM·시장 진입 전략. **일단 영상을 뽑고 판단**
- **기각: "비행기 타기 전에 맡기고 착륙하면 끝나 있다" 컨셉** — 일정 파악·대행은 Pickle 같은 개인 에이전트가 하는 일이라 Counter가 강조되지 않음 → 예약 시스템(가게 쪽) 중심으로 간다

## 데모 시나리오 흐름 (피부과 기준, 최수민 정리)

1. 사용자가 ChatGPT·Muse 등에 요청 — 예: "Find skin care aesthetic in Korea"
2. 에이전트가 검색 → Google Maps 탐색 → 가게의 **Counter 연락 창구 발견** → "연락할게요" (영상에 전체 흐름이 다 나올 필요는 없음)
3. 에이전트끼리 대화(에이전트 네트워킹)
4. Counter가 원장에게 **신규 예약 승인 여부**를 묻고 원장이 승인
5. Counter가 사용자 쪽 에이전트에 예약 완료를 알림

- **알림 채널 문제**: Muse 쪽에 webhook 같은 수신 엔드포인트가 없으면 Counter가 먼저 연락할 수 없다 → 요청을 접수할 때 연락처(주로 이메일)를 물어 두고 이메일로 알린다. 나중에는 에이전트들이 자체 수신 창구를 열 수도 있음
- **보안 우려(영상 주제 아님)**: 에이전트가 공개 연락 창구를 열면 프롬프트 인젝션, 토큰을 태우려는 DoS 공격에 노출된다 — 개인 에이전트들이 수신 창구를 쉽게 못 열 이유

## 논의만 하고 정하지 않은 것

- **이름**: "Counter" 도메인이 비싸고(전사상 try-counter 등 언급), 구글에서 "counter"로 검색 걸릴 자신이 없다. "Contact" 계열 등 다른 후보 이야기가 나왔으나 전사가 불명확해 확정 없음 — 나중에 바꿀 수도 있음
- 챌린지 4번(AI Consumer Products for 1B People) 연결 논리: AI 회사들이 에이전트를 보급하려 경쟁 중 → 그들이 깔아 주는 에이전트가 곧 우리 유저가 된다
- Pickle 관점: Pickle도 전화를 걸었다가 사람들에게 혼나는 피드백 때문에 점점 소극적으로 변하는 중 → Counter로 오면 혼날 일이 없으니 Pickle 입장에서도 반길 것 (심사위원 Pickle CEO 겨냥 포인트)
- 레퍼런스: 공식 홈페이지의 90초 에이전트 소개 영상(어느 회사인지 전사 불명확)을 참고해 한 명이 영상 제작 · 에이전트 두 대(맥북·폰)가 서로 에이전트임을 확인하고 빠르게 대화로 전환하는 영상 · 한 팀원은 모션그래픽 소재를 갖고 있음
