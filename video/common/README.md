# common — 팀 공통 기준

여기 있는 것은 **모든 영상 안이 똑같이 따르는 기준**이다. 캐릭터 생김새·이름·색, 확정된 문구, 공용 소재.

## 격상 규칙

각자 폴더에서 만든 것 중 다 같이 쓸 것을 **1시간 싱크(11:30 · 12:30 · 13:30 · 14:30)마다** 여기로 올린다.

1. 싱크에서 "이건 공통으로 쓰자"고 정한 작업물을 고른다
2. 만든 사람이 자기 폴더에서 `common/`으로 **옮긴다**(복사 말고 이동 — 같은 것이 두 곳에 있으면 어느 쪽이 최신인지 헷갈린다)
3. 아래 격상 기록에 한 줄 적는다
4. common의 내용을 바꾸고 싶으면 다음 싱크에서 말한다. 싱크 사이에는 고치지 않는다 (오타 수정은 예외)
