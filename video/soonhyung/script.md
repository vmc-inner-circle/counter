# Counter — 90초 영상 대본·콘티 v2 (Josh 구성 기반)

- 작성 2026-11-09 · v1(나레이션형) 폐기, Josh 구성(인트로 → 페인 포인트 → 해결 3시나리오 → 클로징)으로 재작성
- 톤: 레퍼런스(Notion 3.0 한국 론칭 영상) — 나레이션 없음, BGM + 화면 텍스트, 크림색 바탕, 큰 한글 키네틱 타이포, 악센트 단색 위에 UI 카드, 캐릭터 말풍선
- 제작 도구: Barty-Bart/motion-graphics의 `explainer-default`(HTML `seek(t)` → Playwright 렌더 → MP4, 모션블러) + `sound-effects`(CC0 효과음, -16 LUFS 측정)
- 두 언어판: 화면 텍스트만 한국어/영어로 교체. 시나리오 대사는 각 외국어 원문 + 아래 작은 번역 한 줄(한국어판은 한국어, 영어판은 영어). 자막 바 없음.
- 시간은 Josh 메모대로 참고값. 실제 컷 길이는 모션 템포 보고 조정.

## 0. 한 문장

> 손님이 에이전트가 된 시대, 사장님도 에이전트도 전화가 괴롭다. Counter가 가운데서 받는다. 둘 다 웃는다.

## 1. 등장인물

| 이름 | 역할 | 소스 | 감정 변화 |
|---|---|---|---|
| 사장님 | 식당·피부과·숙소 주인 (한 명으로 통일, 앞치마) | **생성 필요** (Notion풍 선화 캐릭터, 승인 후 힉스필드) | 허둥지둥 → 웃음 |
| 피클 (Pickle) | 전화 거는 AI 에이전트. 혼나는 주인공 | **Josh 제공 또는 캡처 승인 필요** (현재 없음) | 울상 → 웃음 |
| Muse | Meta 에이전트 · 영어 | 덱 1장 이미지 (`소재/deck_img/img-000.png`, 크림색 털 로봇) | — |
| Dots | OpenAI 에이전트 · 베트남어 | 덱 1장 이미지 (`img-001.png`, 노란 삼각형 안경) | — |
| Counter | 가게마다 있는 에이전트 | 덱 임시 캐릭터(흰 삼각형 `img-003.png`) 또는 워드마크만 | 항상 차분 |

감정 표현(울상·웃음)은 캐릭터 이미지 위에 눈·입을 벡터로 덧그려 처리한다. 원본 이미지는 그대로 두고 표정 레이어만 바뀐다.

## 4. 두 언어판 차이

- 화면 텍스트(타이포·말풍선·UI 라벨)만 바뀐다. 시나리오 대사는 영어·중국어·베트남어 원문 그대로, 번역 줄만 한국어↔영어.
- 영어판 C1은 원문이 영어라 번역 줄 없음. 한국어판 C1은 한국어 번역 줄.
- 태그라인(D3)은 양쪽 다 영어.

## 5. 확정 필요 · 리스크

| 항목 | 상태 | 기본값(Josh 결정 전) |
|---|---|---|
| 피클 이미지 | 없음 | Josh가 파일 주시거나, 공식 사이트에서 가져오는 것 승인 |
| 사장님 캐릭터 | 없음 | 승인 후 힉스필드로 Notion풍 선화 1장 생성 (표정 2종은 벡터 덧그림) |
| 중국어·베트남어 대사 | 작성함 | **원어민 검수 미완**. 영상에 들어가기 전 팀 내 확인 필요 |
| BGM | v1 BGM은 어두움 | 밝은 플럭 계열로 다시 생성(일레븐랩스) 또는 CC0 트랙 선택 |
| Counter 캐릭터 | 덱도 임시 | 워드마크만 쓰는 것으로 가고, 캐릭터는 C0에서만 작게 |
| 시나리오 UI | 목업 | 최수민 님 빌드가 나오면 실제 화면 녹화로 교체 (C1~C3) |
| 혼내는 손님(B4) | 얼굴 없음 | 폰 화면 말풍선으로만 처리, 사람 그림 안 그림 |
